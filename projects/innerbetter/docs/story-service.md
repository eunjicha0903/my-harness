# 이너베러 서비스 유저스토리

> 출처: [prd.md](prd.md) + 사용자 확인 사항 (2026-10-05)

## 유저스토리

| #   | 유저스토리                                                                                                                           | 근거                          |
| --- | ------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------- |
| 1   | **저칼로리 식단을 관리하는 사용자**가 건강식품을 카테고리별로 찾아보고, 가격·칼로리·영양성분을 확인한다.                             | PRD 3-1, 6-1, 6-2             |
| 2   | **저칼로리 식단을 관리하는 사용자**가 상품을 장바구니에 담고, 수량을 바꾸면서 최소 주문 금액을 채웠는지와 최종 결제 금액을 확인한다. | PRD 3-2, 6-3                  |
| 3   | **상품을 주문하는 사용자**가 주문 마감 시간(배달시간 1시간 전) 전에, 적립금이 자동으로 적용된 금액으로 결제해 주문을 완료한다.       | PRD 3-2, 6-4, 7 / 사용자 확인 |
| 4   | **무인 배달을 이용하는 사용자**가 주문 상세에서 내 주문이 지금 어느 단계(배송 준비중 → 배송 중 → 배송 완료)인지 확인한다.            | PRD 3-3, 6-6, 6-7             |
| 5   | **무인 배달을 이용하는 사용자**가 배송 준비중이고 취소 가능 시간(배달시간 1시간 전) 이내인 주문을 취소한다.                          | PRD 3-3, 6-7 / 사용자 확인    |

## 이 서비스에서 어기면 안 되는 것

| #   | 규칙                                                                                                                                             | 근거                         |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------- |
| 1   | **최소 주문 금액을 채우지 못하면 주문할 수 없다.** 부족한 금액을 알려주고 주문 진행을 막는다.                                                    | PRD 4, 6-3, 13               |
| 2   | **주문 취소는 배송 준비중일 때, 배달시간 1시간 전까지만 된다.** 배송 중부터는 취소할 수 없고, 취소할 수 있는지는 현재 주문 상태와 같이 보여준다. | PRD 6-7, 7, 13 / 사용자 확인 |
