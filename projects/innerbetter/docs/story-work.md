# 이너베러 디자인 작업 방식 (AI 없이 했던 마지막 작업)

> 이 문서는 "내가 실제로 어떻게 했는지"를 기록한 것입니다.
> "무엇을 위한 일인지"는 [story-service.md](story-service.md)를 기준으로 합니다.

## 작업 문장

1. 나는 uibowl에서 경쟁사 레퍼런스를 수집한다.
2. 나는 레퍼런스를 토대로 분석하고 우리 서비스에 반영할 부분을 가져온다.
   - ⏸ 멈칫: 화면 목적과 클라이언트 니즈를 충족하는, 서비스에 반영할 부분이 맞는지
3. 나는 분석 내용을 토대로 우리 서비스 화면 설계 문서를 구체화한다.
4. 나는 Figma에 레퍼런스와 화면 설계서를 반영한 UI 키스크린 2~3개를 375×812 크기로 그린다.
5. 나는 내부 관계자들과 협의한 뒤 컨셉 시안을 확정한다.
6. 나는 컨펌된 시안을 기반으로 디자인 토큰과 컴포넌트를 만들고 화면 디자인에 들어간다.
7. 나는 완성된 시안에서 토큰이나 컴포넌트가 우리 가이드를 위반한 부분이 없는지 검토한다.
