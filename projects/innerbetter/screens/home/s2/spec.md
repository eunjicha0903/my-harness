## 연결 유저스토리

## 상태 목록

상태 ID는 Figma 프레임 이름 `<화면>/<상태 ID>`에 그대로 쓴다. rules.json `screens.<화면>.requiredStates`가 있으면 모두 포함.

| 상태 ID | 설명 |
|---|---|
| default | 홈 첫 진입. 검색바, 카테고리 그리드, 카테고리별 상품 섹션(첫 번째 하위 카테고리 탭 선택)이 노출된 기본 상태. Figma 프레임 `home/default` |

- rules.json `screens.home`에는 `requiredStates`가 없다.
- 로딩·상품 없음(빈 섹션)·네트워크 오류 같은 상태는 PRD·story-service.md에 정의가 없어 추가하지 않았다. [확인 필요] 필요하면 상태 ID와 노출 문구를 알려주세요.

## 화면 구성

프레임 375×812, 좌우 여백 20 (rules.json `design.sideMargin`). `bg`, `status-bar`, `top-bar`, `bottom-area`는 여백 예외 레이어(rules.json `design.marginExemptLayers`).

rules.json `naming.layers`(btn-order, btn-cancel, txt-shortfall, txt-cancel-deadline)는 장바구니·주문 상세용이라 홈 화면에는 해당 레이어가 없다. story-service.md "어기면 안 되는 것" #1(최소 주문 금액), #2(주문 취소 시간)는 홈 화면 요소와 직접 걸리지 않는다.

위 → 아래:

1. **상태바** `status-bar`
   - 시스템 상태바.

2. **헤더** `top-bar`
   - 좌: 서비스 로고(이너베러).
   - 우: 장바구니 아이콘 (PRD 6-1 "장바구니 접근") → cart 화면으로 이동.
   - 우: 마이 아이콘 (PRD 6-1 "마이페이지 접근") → my 화면으로 이동.
   - 알림 아이콘은 넣지 않는다. PRD 6-1에는 "알림 접근"이 있으나 story-service.md "이번 범위에서 제외"에 알림이 있어 이를 따른다. [확인 필요]
   - 장바구니 아이콘의 담긴 수량 배지 표시 여부는 문서에 없다. [확인 필요]

3. **검색바** (반영 항목 #1)
   - 헤더 바로 아래 고정. 스크롤해도 헤더와 함께 상단에 남는다.
   - 자리표시 문구는 문서에 없다. [확인 필요]
   - PRD 6-1 필수 기능에 "검색"은 없고, 검색 결과 화면도 rules.json `screens`에 없다. 탭했을 때 이동할 화면 [확인 필요].

4. **카테고리 그리드** (반영 항목 #2, #3)
   - 스크롤 전 첫 화면 안에 노출. 아이콘 + 라벨, 최대 5열×2행.
   - 각 카테고리 탭 → product-list 화면(해당 카테고리로 필터된 상품 목록)으로 이동 (PRD 11 플로우: 홈 → 카테고리 → 상품 목록).
   - 카테고리 이름·개수·아이콘은 문서에 없다. [확인 필요]
   - 그리드 아래 "전체 카테고리 보기" 링크. 이동할 화면 [확인 필요] — PRD 5 IA에는 "카테고리"가 있으나 rules.json `screens`에 별도 카테고리 화면이 없다.

5. **상품 섹션** (반영 항목 #4, #8) — 세로로 1개 이상 반복
   - 섹션 제목 + 우측 "전체보기" 버튼 → product-list 화면으로 이동.
   - 섹션 제목 아래 하위 카테고리 텍스트 탭(가로 스크롤). 탭을 바꾸면 아래 상품 카드 목록이 해당 카테고리 상품으로 바뀐다. 선택된 탭은 강조 표시.
   - 상품 카드 가로 스크롤 목록.
   - 섹션 주제는 카테고리 기준으로 한다. PRD 9 MVP 제외("고도화된 개인화 추천", "콘텐츠 중심 피드")와 PRD 10 Phase 3(추천·인기·기획전은 이후 확장)에 따라 "추천/인기/기획전" 섹션은 만들지 않는다.
   - 섹션 개수·섹션 제목 문구는 문서에 없다. [확인 필요]

6. **상품 카드** (반영 항목 #5, #6, #7) — 상품 섹션 안
   - 상품 이미지 (PRD 8 Product.image).
   - 상품명 (PRD 8 Product.name).
   - 판매가: 상품명 아래, 카드 안에서 가장 강조 (PRD 6-1 "상품 가격", Product.price).
     - 할인 시 정가(취소선)·할인율 병기. 단, 상품 단위 할인(정가/할인가) 데이터는 PRD 8 Product에 없다 (Product.price만 있음). 할인 표시 사용 여부 [확인 필요].
   - 칼로리: "숫자 + kcal" 형식, 판매가와 같은 줄 또는 바로 아래 (story-service.md 유저스토리 1 "칼로리").
   - 영양 칩: 핵심 영양 수치를 "숫자 + 단위" 작은 칩으로 표시 (PRD 8 Product.nutrition). 어떤 영양소를 몇 개 노출할지 [확인 필요] (s1 반영 항목은 "단백질 등"으로만 기재).
   - 카드 탭 → product-detail 화면으로 이동.
   - 빠른 장바구니 추가 버튼은 넣지 않는다. PRD 6-1·9에는 "빠른 장바구니 추가"가 필수/MVP 포함으로 있으나, 승인된 s1 반영 항목에서 스토리 2 영역으로 제외되었다. 둘이 충돌하므로 [확인 필요].

7. **하단 영역** `bottom-area`
   - 하단 탭바는 문서에 정의가 없어 두지 않는다 (장바구니·마이 접근은 헤더에 배치). 하단 탭바 사용 여부 [확인 필요].

- 배달 가능 시간(story-service.md 배달 시간 정책, 예 18:00 ~ 21:00)·주문 마감 시간을 홈에 노출할지는 문서에 화면 지정이 없다. [확인 필요]
