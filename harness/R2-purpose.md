# R2. 목적

## 단위

- 프로젝트: 매번 새로 생성. 프로젝트 폴더 안에 아래 4개 문서를 새로 둔다.
  - prd.md / story-service.md / story-work.md / design.md
  - design.md는 공용 하네스가 아니라 프로젝트 폴더에 두고, 해당 프로젝트 와이어프레임 작업에 필요한 내용만 관리한다.
- 공용: 하네스(에이전트, 게이트, 판정 스크립트)는 모든 프로젝트가 같이 쓴다.
- 실행 1회 = 화면 1개 (PRD의 핵심 화면 목록 중 1개를 지정)
  - 지정한 화면과 관련된 story-service.md 유저스토리 번호를 연결

## 고정 vs 반복 (프로젝트 안에서)

| 구분 | 항목 | 시점 |
|---|---|---|
| 고정 | 컨셉 시안, 디자인 토큰, 컴포넌트 | 프로젝트 첫 실행에서 1회 확정 |
| 반복 | 레퍼런스 → 분석 → 화면 설계 → 화면 디자인 → 검토 | 화면마다 |

## 사용자

- 실행: 본인 (프로덕트 디자이너)
- 결과 수신: 본인 (프로덕트 디자이너)
- 컨셉 시안 확정(작업 흐름 5단계): 본인 승인. 내부 관계자 협의는 하네스 밖에서 진행.
